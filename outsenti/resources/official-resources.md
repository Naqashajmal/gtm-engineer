## What a GTM engineer actually does (real job posts)

Read these first. They show the real job, not a blog's guess.

1. **Didomi — Outbound GTM Engineer**
   https://jobs.lever.co/didomi/3efb0fb4-3fd6-4e88-b68e-f0c657d41ff4
   - Owns data, signals, scoring, automation for outbound
   - Tools: ZoomInfo, Clay, Lemlist, Salesforce
   - Build: ICP → sequences → A/B testing → personalization at scale

2. **SalesCaptain — Senior GTM Engineer**
   https://euremotejobs.com/job/senior-gtm-engineer
   - Builds end-to-end outbound systems: ICP → TAM → enrichment → sequencing → CRM sync → reporting
   - Owns Clay workflows, email deliverability (SPF, DKIM, DMARC), signal-based targeting
   - Uses n8n, Make, Zapier, APIs, webhooks
   - Writes Python/JavaScript when no-code is not enough

3. **Suger.io — GTM Engineer**
   https://jobs.lever.co/suger/5ec19116-4614-4931-ab8c-8d8fa0afd52a
   - Scrapes and transforms data into actions across email, SDR outreach, web
   - Builds trigger-based outbound from high-intent signals
   - Uses OpenAI API + third-party APIs for personalization at scale
   - Python, SQL, JavaScript

**What all three share:** data + automation + signals + outbound. No pure "sales" or pure "marketing." It is engineering applied to go-to-market.
