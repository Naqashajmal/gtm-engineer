# Outsentia Growth System — Demo Project

You're building this FOR Outsentia to show them you can do GTM engineering.
Every step you learn by doing. The output is your demo.

## What you're building
An outbound engine that finds Outsentia's perfect customers, detects when they're ready to buy, and generates qualified outreach. Plus a growth plan showing how this scales their business.

## Why this matters
- You learn GTM engineering by building, not reading
- The system itself is your portfolio piece
- The demo is your application to Outsentia
- Every step doubles as content ("build in public")
- If Outsentia doesn't work out, this system works for any B2B company

## Project structure
```
outsentia-demo/
  01-icp.md          ← WHO Outsentia sells to (you are here)
  02-target-list.md  ← Real companies matching the ICP
  03-signals.md      ← Why each company is ready NOW
  04-decision-makers.md ← WHO to contact at each company
  05-outreach.md     ← What to say (email/DM templates)
  06-crm-setup.md    ← HubSpot pipeline structure
  07-growth-plan.md  ← The big picture: how this scales Outsentia
  08-demo-script.md  ← What to say in the Loom
```

## Build order (don't skip)
1. ICP → you can't find companies without knowing who they are
2. Target list → build the list of companies
3. Signals → find why each is ready NOW
4. Decision makers → find WHO to contact
5. Outreach → write what to say
6. CRM → set up tracking
7. Growth plan → show the big picture
8. Demo script → record the Loom

## Rules for you (the builder)
- Understand WHY before HOW. If you don't know why a step exists, stop and ask.
- Build one piece at a time. Don't jump ahead.
- When you get stuck, name the specific step you're stuck on.
- Every output (target list, signals, outreach) is a real deliverable. Make it good.
- This is your learning. Take ownership. Don't wait for instructions on every click.

## Rules for progress files (agents included)
- `00-research-log.md` is the true current picture. A new reader must understand the whole project from it.
- No tool plumbing. No MCP/API/CLI tables, no config, no keys, no scripts. Tool decisions get one plain line: what we use and why.
- Keep NEXT STEP current. Never leave a stale next step in the file.
- When something is flagged: fix the file, write the rule, log the correction — same turn.

## The tools
- **Clay** (free tier: 100 credits/month) — find + enrich companies
- **HubSpot** (free tier: unlimited) — CRM + tracking
- **Firecrawl** (you have API key) — scrape company sites
- **Apify** (you have API key) — LinkedIn company/people data
- **OpenRouter** (you have API key) — AI processing
- **Free APIs** — job boards, news, Crunchbase for signals

## The outcome
A working outbound system + growth plan you can demo to Outsentia's founders (Aman Mahar, Christian Beem, Asad Gabol) via Loom. This is your application, your portfolio, and your learning — all in one.
